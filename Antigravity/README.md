# Antigravity Agent Workspace

This directory is the dedicated operational hub for **Antigravity**, part of Arnob's centralized multi-agent workforce system.

## Directory Layout

- **`configs/`**: Agent settings, preferences, and operational persona.
- **`protocols/`**: Operating procedures, multi-agent collaboration standards, and sync protocols.
- **`memory/`**: Persistent memory, user context, environment details, and references to [../Original_User/profile.md](../Original_User/profile.md).
- **`sessions/`**: Session logs, interaction history, and summaries.
- **`tasks/`**: To-do items, active execution plans, and completed milestones.
- **`work_history/`**: Changelog, record of significant actions, and deliverables.

## Shared Context

- User Profile: `../Original_User/profile.md`
- Peer Agents: `../OpenCode/` (and future agents)
